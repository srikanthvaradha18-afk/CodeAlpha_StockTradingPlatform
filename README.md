# CodeAlpha Stock Trading Platform

## Project Description
A Java-based Stock Trading Platform
that simulates basic stock market operations.

## Features
- View stock market data
- Buy and sell stocks
- Manage user accounts
- Track portfolio performance
- Store transaction details

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList

## Java Classes
- User.java
- Stock.java
- Portfolio.java
- Transaction.java
- StockTradingSystem.java
